🗄️ PocketBase Database
URL PocketBase server kamu. Default localhost untuk development.
Setup PocketBase:
1. Download pocketbase di pocketbase.io → jalankan ./pocketbase serve
2. Buka http://127.0.0.1:8090/_/ → buat collections students & submissions (lihat POCKETBASE_SETUP.txt)
3. Set API Rules semua ke true (public) biar siswa bisa setor tanpa login
4. Paste URL di sini → Test → harus ✅ Konek!
⚙️ Google Sheets Edit di Excel
Tempel URL Web App dari Apps Script. Jika kosong, tetap jalan offline.
Setup 3 menit: Buat Sheet baru → Extensions → Apps Script → Paste kode APPS_SCRIPT_GSHEETS.txt → Deploy Web App Anyone → Copy URL → Paste di sini. Teachers bisa edit XP langsung di Sheet!
